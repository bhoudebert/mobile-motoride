# Testing "Get a server" on a real phone

The first end-to-end check of the hosted free server, to run once the sidecar is deployed at
`https://sidecar-motoride.memorledge.app` and before a release carries it. About ten minutes, on a phone with the build to test
(an installed release or a development build) and a mobile connection or Wi-Fi. Each step says what you do and what you must
see; if you see something else, stop, note the step and what appeared, and take a screenshot.

Before you start: the phone has **no server** set (Menu, Server: "What a server adds" and "Get a server" are shown). If it has
one, write down its address and token, remove it, and put it back at the end. A build made with
`EXPO_PUBLIC_HOSTED_SERVER=0` shows no "Get a server": use another.

## Failures worth provoking once

- Sidecar unreachable (airplane mode at step 2): "The service cannot be reached. Check the network and try again."
- Free servers full (the sidecar's `SIDECAR_FREE_CAP` reached or `SIDECAR_FREE_ENABLED` off): "Free servers are full for now. Try again later."
- Paused server (the sidecar or agentRide suspends the rider): the Server screen says "Your server is paused", what is kept and
  until when, and offers no code for a chat; the ride screen shows nothing about it.
- Deleted behind the app's back (delete the rider on the server): the Server screen says "This phone's access to the server is no
  longer valid. It may have been deleted."
